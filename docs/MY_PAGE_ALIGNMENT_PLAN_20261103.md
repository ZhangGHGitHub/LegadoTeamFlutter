## 一、现状与基线

### 1.1 我方「我的」页当前结构

从上到下：

1. 大标题「我的」+ 帮助按钮（`LegadoLargeTitleScroll`）。
2. 无标题分组（`IosGroup`）9 行：
   - 书源管理、定时任务、运行定时任务、TXT 目录规则、替换净化、字典规则、规则管理、高亮标注、主题模式。
3. Web 服务大卡（独立描边卡片，整卡开关，开启后副题显示 `running on port X`；**无复制地址/浏览器打开按钮**）。
4. MCP 服务分组（单开关）。
5. 「设置」分组：单一「设置」入口。
6. 「其他」分组：书签、阅读记录、缓存管理、文件管理、关于、退出。

### 1.2 参考版「我的」页结构（目标）

1. 顶部栏「我的」，无帮助按钮。
2. 无标题分组：**Web 服务块**（`SwitchSettingItem`：图标+标题+状态/地址；运行中展开「复制地址」「在浏览器中打开」两个按钮）。
3. 「规则」分组：书源管理、替换净化、TXT 目录规则、字典规则、高亮标签规则。
4. 「其他」分组：AI 聊天、设置、书签、阅读记录、缓存管理、文件管理、关于、退出。

### 1.3 原版「我的」页结构（语义备份）

- 顶层：书源管理、定时任务、运行定时任务、TXT 目录规则、替换净化、字典规则、主题模式、Web 服务、MCP 服务。
- 「设置」分类：备份与恢复、主题设置、其他设置。
- 「其他」：书签、阅读记录、文件管理、关于、检查更新、检查 Beta 更新、退出、更多。
- 原版无「缓存管理」「高亮标注」「规则管理」「AI 聊天」入口（这些来自参考版或我方后续补齐）。

### 1.4 差异结论

| 差异 | 我方 | 参考版 | 原版 | 建议 |
|---|---|---|---|---|
| Web 服务位置/形态 | 规则组之后的大卡；无复制/打开按钮 | **顶部**块；运行中显示复制地址/打开浏览器 | 顶层开关行 | 按参考版：移到顶部，补两个操作按钮 |
| 规则组 | 混入定时任务/运行开关/规则管理/主题模式 | 仅 5 个规则入口 | 9 个顶层项 | 规则组收敛为 5 项；原版独有项另设「服务与工具」组 |
| 定时任务/运行开关 | 规则组内 | 无 | 顶层 2 项 | 保留，移入「服务与工具」 |
| MCP 服务 | 独立分组 | 无 | 顶层开关 | 保留，移入「服务与工具」 |
| 主题模式 | 规则组内快捷入口 | 无（设置→外观） | 顶层项 | 建议移入「服务与工具」或删除快捷入口（设置内已有） |
| 字典规则/规则管理 | 两个入口 | 单一「字典规则」 | 单一「字典规则」 | 合并为一个「字典规则」入口：列表管理为主，查询作为页内操作 |
| 高亮标注 | 规则组 | 规则组「高亮标签规则」 | 无 | 保留，文案对齐「高亮标签规则」 |
| 缓存管理 | 其他组 | 其他组 | 无 | 保留（与参考版一致） |
| 设置入口 | 设置组单项 | 其他组「设置」 | 设置分类 | 按参考版并入「其他」组，移除独立「设置」组 |
| AI 聊天 | 无 | 其他组入口 | 无 | **待裁决**：属参考版独有功能，未获新增功能授权前不加 |
| 帮助按钮 | 大标题右侧 | 无 | 更多菜单 | 建议保留（不改变信息架构）或移入关于；待确认 |
| 检查更新 | 无（关于页有） | 无 | 其他组 2 项 | 不新增（关于页已有检查更新） |

## 二、目标信息架构（建议）

```
我的（大标题 + 帮助按钮）
├─ [无标题分组] Web 服务块（开关 + 运行地址 + 复制地址 / 在浏览器中打开）
├─ 规则
│   ├─ 书源管理
│   ├─ 替换净化
│   ├─ TXT 目录规则
│   ├─ 字典规则（合并原「规则管理」入口）
│   └─ 高亮标签规则
├─ 服务与工具（原版独有，保留能力）
│   ├─ 定时任务
│   ├─ 运行定时任务（开关）
│   └─ MCP 服务（开关）
├─ 其他
│   ├─ AI 聊天（占位）
│   ├─ 设置
│   ├─ 书签
│   ├─ 阅读记录
│   ├─ 缓存管理
│   ├─ 文件管理
│   ├─ 关于
│   └─ 退出
```

> `服务与工具` 是原版能力保留区，不冒充参考版。主题模式按参考版不再出现在「我的」页，统一从「设置 → 外观」进入。

## 三、分批实施

### 批 M1（P0：信息架构与 Web 服务块）
- 将 Web 服务块移到页面顶部；运行中在块内显示地址、「复制地址」「在浏览器中打开」两个按钮（复用剪贴板/`url_launcher`，失败提示）。
- 规则组收敛为 5 项（书源/替换/TXT/字典/高亮）；新增「服务与工具」组，迁入定时任务、运行定时任务、MCP；**移除主题模式快捷入口**（设置→外观已有）。
- 移除独立「设置」组，把「设置」入口并入「其他」组（书签之前，按参考版顺序）。
- 合并「字典规则」与「规则管理」为单入口（默认进管理页；旧 `AppRoutes.dictRule` 路由重定向/保留深链，查询能力页内可达）。

- 文件：`settings_screen.dart`（主）、新增 `ai_chat_placeholder_screen.dart`（或等价）、`app_strings.dart`、`routes.dart`。
- 测试：分组/条目快照、Web 服务复制/打开、AI 占位导航、入口导航、MCP/定时任务仍可达、主题模式不在 My、返回栈。
- 验收：默认/运行中/停止三态、剪贴板内容、浏览器打开、AI 占位页、Android/iOS。

## 五、验收与风险

- 不改 Rust/FFI；Web 服务开关仍复用现有前台服务/唤醒锁/保活链路，复制/打开仅为 UI 操作。
- 移动 Web 服务块不改变其状态机；MCP/自动任务/主题模式仅迁移入口，不改逻辑。
- 字典规则合并若改变默认落点，需保留原路由重定向，避免深链/旧入口失效。
- 视觉改动按参考版；与已确认的 LargeTitle/容器样式设置叠加时以当前主题配置为准。
- 每批：`flutter analyze && flutter test`，设备验收后更新 Active 计划与双日志。
