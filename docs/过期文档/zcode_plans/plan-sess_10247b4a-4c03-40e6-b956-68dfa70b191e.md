## 0. R3/R4 定版解释（先答疑问）
- **R3“塌缩为 light”≠没有跟随系统**：Flutter 侧 `ThemeMode.system` 跟随系统完整存在且生效（theme_notifier/settings_service/app.dart），用户选项不受影响。塌缩仅发生在 Rust→JS 透传层：`get_theme_mode()` 把注入值 "0"（跟随系统）映射成 `"light"`，导致书源 JS 调用 `getThemeMode()` 时永远看不到 `auto`，暗夜下 JS 逻辑误判。本次 R3 只改该映射为 `"0"→auto`（None 未注入仍回退 light），Flutter 注入 `"0/1/2"` 不变，需双轨评审（有源依赖 auto 分支则行为变化）+ 契约登记 + `cargo test -p legado-js`。
- **R4（已确认新增 FFI）**：新增 `set_read_book_config(read_json)` void 进程注入，对齐 `set_theme_config` 模式：`legado-js` 新增 `set_injected_read_book_config` + `get_read_book_config` 优先返注入；`ffi.rs` 导出；codegen 重生成 + cargo 重编保 hash；Dart `RustApi.init` 在主题注入后追加阅读配置注入（读当前阅读配置合成 JSON）；Mock 加空实现；契约先行（§1.6.1 登记，不进 BookApi 计数，与 set_theme 三件套同列）。
