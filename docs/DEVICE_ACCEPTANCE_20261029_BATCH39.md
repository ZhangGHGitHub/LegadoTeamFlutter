## 一、回修项登记

### 1.1 RSS 阅读页 `java.openUrl` 接入浏览器拦截（P2-5）

- `RssArticleDetailScreen` 宿主桥动作 `openUrl` 与书源 JS 桥同口径：
  - 开启「拦截书源打开浏览器」后一律拦截，提示统一文案
    **「已阻止书源打开浏览器」**（`kSourceBrowserBlockedMessage`）；
  - `legado://` / `yuedu://` 关联导入属站内链路，不交浏览器、不受拦截。
- 同时把 `openBrowser` / `startBrowser` 的深链分流补齐（此前只有 `openUrl`
  先判链接协议），文案中性化去掉「内置」（`startBrowser` 可能外开）。
- 覆盖用例：`test/widget/rss_web_bridge_wiring_test.dart`（+2）、
  `test/widget/source_browser_block_test.dart`（+2，深链豁免）。

**设备验收核对**：开启开关后，RSS 正文内点击 `java.openUrl` 触发的链接应只
出现提示、不弹「跳转确认」、不打开浏览器；`legado://` 导入链接仍进导入页。

### 1.2 发现网格「首比例统一」语义（P3-8）

关闭「限制封面比例」后：

- 发现网格与书架网格的行高都取「可见书中**第一个已解析**的原图比例」，
  **整格统一**（不同书比例不同也不逐卡变化），保证行高稳定；
- 限制比例开启（默认）时发现网格沿用既有 3:4 基准、书架网格沿用 5:7；
- 首个比例未知时回退调用方声明尺寸（不再硬套 5:7）。

**设备验收核对**：关闭开关后进入发现分类（网格模式）/书架网格，行高应
整屏一致，滚动不出现逐行高度跳变。

### 1.3 封面比例修订号门控（P2-3）

「限制封面比例」开启（默认）时，网格行高固定，逐张封面解析完成不再递增
`coverAspectRatioRevision`（仅进程内首个已知比例通知一次），避免书架/发现
网格整屏重建；关闭时才逐张通知重算。

**设备验收核对**：默认设置下快速滚动书架/发现网格，不应出现周期性整屏闪烁。

### 1.4 发现列表交互（P2-1 / P2-2）

- 加载上一页的滚动锚点改为**请求返回后**采集（慢网期间用户滚动不会被拉回）；
- page > 1 时顶部下拉仍为「加载上一页」，顶栏新增**刷新**入口（任何页可用，
  回到第 1 页）；刷新被忽略（加载在途）时提示「正在加载，请稍候再刷新」。

**设备验收核对**：慢网/飞行模式切回后触发上一页，列表不应跳回旧位置；
第 3 页点顶栏刷新应回到第 1 页并显示最新榜单。

### 1.5 网络章「缺图」重抓：登记差异（P3-11）

- 参考版批量下载用严格口径（`BookHelp.isChapterCacheComplete`：正文 + 章节
  内图片均已缓存），缺图章视为未完成 → 重抓；
- 本仓 `cache_download_api::download_one` 的在线书分支复用
  `get_chapter_content_full`（**cache-first**：正文非空即返回），因此「有正文
  但图片未落盘」的缓存行**不会重抓**；
- 补齐需要：解析缓存正文 `<img src>`（含相对 URL 解析）逐张校验图片磁盘
  缓存 + 绕过正文缓存抓取 + 下载时同步缓存图片（否则相对图片 URL 章节会
  每次重复联网）——属功能级改动，本批登记不改；
- 锁行为用例：`cache_download_api::tests::
  test_network_chapter_missing_image_is_not_refetched_registered_gap`
  （断言当前 0 次章节请求；严格口径落地后应改为断言重抓）。
