## 7 已知问题与后续建议

### 7.1 已知问题

1. **书籍详情 type cast bug**
   - 现象：本地 txt 书籍打开时报 `type '_Map<String, dynamic>' is not a subtype of type 'List<dynamic>'`
   - 定位：`lib/src/services/rust_api.dart` 中 `getChapters()` 返回类型处理
   - 影响：书籍详情/阅读器章节加载受阻
   - 建议：新建任务修复 FFI 契约容错

2. **响应式网格未验证**
   - 窄屏 2 列/宽屏 4 列切换需不同屏幕尺寸验证
   - 模拟器 720x1280 仅能验证单一尺寸

### 7.2 后续建议

1. 修复书籍详情 type cast bug（P1）
2. 补充响应式网格多尺寸验证
3. 补充书源/订阅源数据验证非空状态
4. 考虑主题配色可配置化（兼容原版棕褐/红色）
5. Release 构建验证（去除调试符号）
