# Legado M3 界面效果图

基于 app/src/main 源码结构绘制的 Material 3 移动端高保真 SVG 稿。统一使用源码 primary=@color/md_light_blue_600 作为动态色种子近似值，并用语义化颜色角色。

- 01_bookshelf.svg：书架
- 02_discovery.svg：发现
- 03_rss.svg：RSS
- 04_my.svg：我的/设置
- 05_search.svg：搜索结果
- 06_book_detail.svg：书籍详情
- 07_toc.svg：目录
- 08_reader_day.svg：阅读器（日间）
- 09_reader_night.svg：阅读器（夜间）
- 10_source_manage.svg：书源管理

每张图为 390×844 竖屏手机画板，含系统状态栏。当前会话未提供内置 image_gen，且未配置 OPENAI_API_KEY，因此使用可复现 SVG 作为高保真交付图。
