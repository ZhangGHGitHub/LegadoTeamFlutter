## 四、观察项（不影响验收）

1. **开启「启动应用时验证」的即时效果**：在本次会话中打开该开关后，应用立刻弹出启动锁（因为本会话的 `appStartVerified` 从未置位），而页面说明写的是「下次启动应用时需要密码」。属更严格的安全侧行为，不会放行内容；文案与行为可在后续批次统一（P3）。
2. **adb 注入对关闭态 DropdownButton 偶发不触发**：同一坐标 `input tap` 两次未打开宽限下拉，改用 120ms 的 `input swipe` 同点触发后正常打开并可选值。Widget 测试已覆盖 onChanged 链路，判定为注入层抖动，非 UI 缺陷（P3）。
3. 模拟器为硬件键盘模式，锁屏/对话框输入由 `input text` 注入，未弹出软键盘；键盘避让（AnimatedPadding）由 Widget 测试覆盖（P3）。
