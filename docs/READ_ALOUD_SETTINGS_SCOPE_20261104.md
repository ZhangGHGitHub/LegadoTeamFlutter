## 二、关键能力缺口

1. **系统 TTS 未接入播放**：Android `TtsBridge` 仅 init/speak/stop/setLanguage/setSpeed/setPitch/isSpeaking；iOS 才走 flutter_tts。flutter_tts 4.2.5 支持 getEngines/getVoices/setEngine/setVoice/synthesizeToFile（Android/iOS）。
2. **pitch/volume/voiceName 在 HTTP 链路被丢弃**：`rust_api_media_format.part.dart:355-359` 只传 text/engineUrl/speed；Rust `tts_speak.rs` 模板仅 GET 占位符。
3. **无朗读设置页**：`read_aloud_config_screen.dart` 仅 HTTP 引擎 CRUD。
4. **胶囊/多角色/BGM/AI/云 TTS/流式**无后端；胶囊需原生 overlay（可复用视频悬浮窗权限）。
