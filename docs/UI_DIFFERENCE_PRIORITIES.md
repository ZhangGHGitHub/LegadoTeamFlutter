# Legado UI 差异优先级分类文档

**分类日期**: 2026-07-30  
**分类目标**: 将界面差异按重要程度分类，制定修复优先级  
**分类依据**: 功能完整性、用户体验、视觉一致性、实现难度

---

## 分类标准

### P0 - 关键差异（必须修复）
**定义**: 严重影响核心功能或用户体验的差异  
**特征**:
- 核心功能缺失或无法使用
- 严重交互逻辑错误
- 导致应用崩溃或数据丢失
- 完全无法接受的用户体验

**修复时限**: 立即修复（1-2 天内）

### P1 - 重要差异（应该修复）
**定义**: 明显影响用户体验或功能完整性的差异  
**特征**:
- 重要功能缺失但可绕过
- 明显交互体验下降
- 视觉风格严重不一致
- 用户可感知的功能差异

**修复时限**: 优先修复（3-5 天内）

### P2 - 次要差异（可选修复）
**定义**: 影响视觉一致性或细节体验的差异  
**特征**:
- 样式细节不一致
- 动画效果差异
- 非核心交互优化
- 像素级渲染差异

**修复时限**: 按需修复（1-2 周内）

### P3 - 微小差异（可忽略）
**定义**: 几乎无法感知或平台特性导致的差异  
**特征**:
- 字体渲染差异
- 动画时序微小差异
- 平台特定适配差异
- 仅在特定设备上可见

**修复时限**: 暂不修复

## 详细差异分类

### P1 - 重要差异（4 项）

#### 1.1 Tab 导航名称不一致
**位置**: `home_screen.dart` 第 4 个 Tab  
**问题**: Flutter 使用"设置"，Android 使用"我的"  
**影响**: 用户认知不一致，与原版体验不符  
**修复难度**: 低（仅需修改字符串）  
**修复优先级**: P1-1（最高）

**修复方案**:
```dart
// 修改前
NavigationDestination(
  icon: const Icon(Icons.person_outline),
  selectedIcon: const Icon(Icons.person),
  label: AppStrings.settings,  // "设置"
),

// 修改后
NavigationDestination(
  icon: const Icon(Icons.person_outline),
  selectedIcon: const Icon(Icons.person),
  label: '我的',  // 与 Android 一致
),
```

**验收标准**:
- [ ] 第 4 个 Tab 显示"我的"
- [ ] 用户可正常切换到该 Tab
- [ ] 功能不受影响

---

#### 1.2 阅读器缺少"无动画"翻页模式
**位置**: `reader_screen.dart` 翻页逻辑  
**问题**: Android 支持 4 种翻页模式（仿真/滑动/覆盖/无），Flutter 仅支持 3 种  
**影响**: 用户无法选择无动画翻页，体验不完整  
**修复难度**: 中（需要添加翻页模式选项和逻辑）  
**修复优先级**: P1-2

**修复方案**:
1. 在翻页模式枚举中添加 `None` 模式
2. 在设置面板中添加"无动画"选项
3. 实现无动画翻页逻辑（直接切换页面）

**验收标准**:
- [ ] 设置面板显示 4 种翻页模式
- [ ] 选择"无动画"后翻页无动画效果
- [ ] 其他翻页模式不受影响

---

#### 1.3 阅读器缺少系统亮度调节
**位置**: `reader_screen.dart` 亮度调节逻辑  
**问题**: Android 支持系统亮度+手动亮度，Flutter 仅支持手动亮度  
**影响**: 用户无法使用系统自动亮度调节  
**修复难度**: 中（需要实现平台通道调用系统亮度）  
**修复优先级**: P1-3

**修复方案**:
1. 创建 `SystemBrightness` 平台通道
2. 在亮度调节面板添加"系统亮度"开关
3. 实现系统亮度读取和设置逻辑

**验收标准**:
- [ ] 亮度面板显示"系统亮度"开关
- [ ] 开启后跟随系统亮度
- [ ] 关闭后使用手动亮度

---

#### 1.4 搜索界面缺少分类筛选
**位置**: `search_screen.dart` 筛选逻辑  
**问题**: Android 支持源选择+分类筛选，Flutter 仅支持源选择  
**影响**: 用户无法按分类筛选搜索结果  
**修复难度**: 中（需要添加分类筛选 UI 和逻辑）  
**修复优先级**: P1-4

**修复方案**:
1. 在搜索框下方添加分类筛选器 UI
2. 实现分类筛选逻辑
3. 更新搜索结果以反映筛选条件

**验收标准**:
- [ ] 搜索界面显示分类筛选器
- [ ] 可选择多个分类
- [ ] 搜索结果根据分类筛选

---

### P2 - 次要差异（8 项）

#### 2.1 Tab 导航标签文字显示
**位置**: `home_screen.dart` NavigationBar  
**问题**: Flutter 显示标签文字，Android 隐藏标签文字  
**影响**: 视觉不一致，但不影响功能  
**修复难度**: 低（仅需修改 labelVisibilityMode）  
**修复优先级**: P2-1

**修复方案**:
```dart
NavigationBar(
  labelBehavior: NavigationDestinationLabelBehavior.onlyShowSelected,
  // 或完全隐藏: NavigationDestinationLabelBehavior.alwaysHide
)
```

**验收标准**:
- [ ] 标签文字显示方式与 Android 一致
- [ ] 不影响 Tab 切换功能

---

#### 2.2 Tab 导航图标样式
**位置**: `home_screen.dart` NavigationBar  
**问题**: Flutter 使用 Material Icons，Android 使用自定义 drawable  
**影响**: 图标视觉风格不一致  
**修复难度**: 中（需要设计并替换自定义图标）  
**修复优先级**: P2-2

**修复方案**:
1. 设计 4 个与 Android 一致的图标
2. 导出为 SVG 或 PNG 格式
3. 在 Flutter 中使用自定义图标

**验收标准**:
- [ ] 图标与 Android 版本视觉一致
- [ ] 图标在不同主题下显示正常

---

#### 2.3 书架刷新组件样式
**位置**: `bookshelf_screen.dart` RefreshIndicator  
**问题**: Flutter RefreshIndicator 与 Android SwipeRefreshLayout 样式不同  
**影响**: 下拉刷新视觉体验不一致  
**修复难度**: 中（需要自定义刷新动画）  
**修复优先级**: P2-3

**修复方案**:
1. 使用 `pull_to_refresh` 包或自定义 RefreshIndicator
2. 实现与 Android 一致的刷新动画
3. 调整刷新触发阈值

**验收标准**:
- [ ] 刷新动画与 Android 一致
- [ ] 刷新功能正常

---

#### 2.4 阅读器翻页动画效果
**位置**: `reader_screen.dart` 翻页动画  
**问题**: Flutter 翻页动画效果与 Android 有细微差异  
**影响**: 翻页体验不完全一致  
**修复难度**: 高（需要深入理解 Android 动画实现）  
**修复优先级**: P2-4

**修复方案**:
1. 分析 Android 翻页动画源码
2. 调整 Flutter 翻页动画参数
3. 优化动画曲线和时序

**验收标准**:
- [ ] 翻页动画效果与 Android 接近
- [ ] 动画流畅无卡顿
