# A5 临时目录清扫 — 命令与输出转录（2026-11-11，逐条来自实机执行）

## 0. 环境/路径判定

任务预设路径：/data/data/io.legado.flutter_legado/cache
Flutter 引擎实际 dart:io Directory.systemTemp：
- engine/src/flutter/shell/common/switches.cc:
  command_line.GetOptionValue(FlagForSwitch(Switch::kCacheDirPath),
                              &settings.temp_directory_path);
- engine/src/flutter/shell/platform/android/io/flutter/util/PathUtils.java:
  getCacheDirectory() -> applicationContext.getCodeCacheDir()（注释：This code path is used to set up dart:io's `Directory.systemTemp`）
- libflutter.so 内含唯一字符串 "/data/local/tmp"（Dart 兜底值；本 App 由 --cache-dir-path 覆盖）
结论：本机实际 systemTemp = /data/data/io.legado.flutter_legado/code_cache
