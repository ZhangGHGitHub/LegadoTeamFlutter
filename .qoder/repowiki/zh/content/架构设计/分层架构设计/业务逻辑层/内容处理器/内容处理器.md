## 简介
本文件面向Legado项目的"内容处理器"子系统，系统性阐述网页内容提取、正则表达式引擎、JSON路径查询、内容清洗与规则引擎等关键能力。文档以代码级视角展开，结合架构图、流程图与时序图，帮助读者快速理解HTML解析、DOM操作、CSS选择器支持、模式匹配与捕获组、嵌套数据处理、数组操作、条件过滤、广告去除、链接修复、格式标准化、动态规则加载、执行上下文与错误处理等实现要点，并提供管道示例与自定义规则开发指南。

**更新** 本次更新重点介绍了阅读器净化功能的集成，实现了基于ContentProcessor的内容清洗机制，在读取时自动应用净化规则，提升了内容处理的自动化程度和用户体验。

## 核心组件
- HTML解析与DOM操作：提供HTML文档解析、节点遍历、属性与文本提取、子树裁剪与拼接，支持XPath与类CSS选择器定位。
- 正则表达式引擎：高性能模式匹配、捕获组、替换、预编译缓存与超时保护。
- JSON路径查询：支持嵌套对象与数组的层级访问、索引与切片、条件过滤与聚合。
- 内容清洗：广告去除、链接修复、空白与标签规范化、编码统一。
- 规则引擎：动态规则加载、执行上下文（变量与作用域）、错误隔离与回退策略。
- **阅读器净化**：基于ContentProcessor的自动化内容清洗，在读取时自动应用净化规则，提升阅读体验。

**更新** 新增阅读器净化组件，实现了ContentProcessor-based的内容清洗机制，能够在读取过程中自动应用净化规则，无需用户手动干预。

## 详细组件分析

### HTML解析与DOM操作
- 功能要点
  - 容错解析：兼容不完整或畸形HTML，生成稳定DOM。
  - DOM遍历：支持父子、兄弟、祖先、后代遍历；按属性、类名、标签名筛选。
  - 选择器支持：XPath表达式与类CSS选择器混合使用，便于复杂定位。
  - 节点操作：文本提取、属性读取、子树裁剪、片段拼接。
- 复杂度与优化
  - 选择器编译缓存，避免重复解析。
  - 大文档分块处理，降低内存峰值。
- 错误处理
  - 解析失败降级到文本模式；定位失败返回空集合并记录日志。

```mermaid
flowchart TD
Start(["进入HTML解析"]) --> Parse["解析HTML为DOM"]
Parse --> Valid{"解析成功?"}
Valid --> |否| Fallback["回退为纯文本处理"]
Valid --> |是| Select["应用XPath/CSS选择器"]
Select --> Nodes{"找到节点?"}
Nodes --> |否| Empty["返回空结果并记录"]
Nodes --> |是| Extract["提取文本/属性/子树"]
Extract --> Clean["基础清洗(去空白/转义)"]
Clean --> End(["输出节点集合"])
Fallback --> End
Empty --> End
```

### 阅读器净化功能
- 功能要点
  - ContentProcessor集成：基于内容处理器的统一净化框架。

- 净化策略
  - 选择器净化：基于CSS选择器移除特定元素。
  - 正则净化：使用正则表达式清理文本内容。
  - 语义净化：基于内容语义分析进行智能清理。
- 性能优化
  - 规则缓存与复用，避免重复计算。
  - 并行净化处理，提升大文档处理速度。
  - 增量净化，仅处理变化的内容区域。

## 故障排查指南
- 常见问题
  - 选择器未命中：检查XPath/CSS语法与DOM结构变化。
  - 正则匹配异常：验证模式合法性与标志位设置。
  - JSON路径失败：确认路径存在性与数据类型。
  - 规则执行错误：查看上下文变量与作用域是否正确注入。
  - 净化规则失效：检查净化规则配置与优先级设置。
- 诊断手段
  - 启用详细日志与执行轨迹。
  - 使用最小复现用例与断点调试。
  - 逐步禁用清洗与规则定位问题阶段。
  - 监控净化规则的命中率与执行时间。
