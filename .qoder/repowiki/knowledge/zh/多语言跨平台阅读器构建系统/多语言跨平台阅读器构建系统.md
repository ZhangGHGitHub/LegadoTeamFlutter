Legado 项目采用三引擎混合构建体系，统一管理 Android 原生、Flutter 跨平台 UI 与 Rust 核心引擎的编译、测试与发布流程。

## 构建系统与工具链

### Gradle + Kotlin（Android 主应用）
- 根工程使用 build.gradle 通过 alias libs.plugins.* 集中管理 AGP 8.13.2、Kotlin 2.4.10、KSP 等插件版本
- 依赖版本统一在 gradle/libs.versions.toml 中声明，包含 70+ 个第三方库的版本锁定
- app/build.gradle 配置了 Room KSP 注解处理器、ProGuard 混淆、Cronet 本地库集成、Firebase 支持
- 自定义 download.gradle 从 Google Storage 下载指定版本的 Cronet JAR 和 SO 文件，并生成 MD5 校验元数据

### Cargo Workspace（Rust 核心引擎）
- rust/Cargo.toml 定义 8 个 crate：legado-core、legado-parser、legado-net、legado-js、legado-book、legado-db、legado-ffi、legado-server
- 通过 [workspace.dependencies] 集中管理 serde、tokio、thiserror 等核心依赖版本
- 使用 rust-toolchain.toml 固定 Rust 工具链版本

### Flutter 跨平台应用
- flutter_legado/pubspec.yaml 声明 flutter_rust_bridge ^2.7.0 作为 Rust FFI 桥接层
- 支持 Android、iOS、Windows、Linux、macOS、Web 六平台构建

## 构建脚本与自动化

### 顶层 Makefile（统一入口）
check: cd rust && cargo check --workspace
test: cd rust && cargo test --workspace
lint: cd rust && cargo clippy --workspace -- -D warnings && cd flutter_legado && flutter analyze
ci: lint test-all
build-android: cd rust && ./scripts/build-android.sh

### Rust Android 交叉编译
- rust/scripts/build-android.sh 自动安装 aarch64/armv7/x86_64 三个目标架构
- 编译产物 liblegado_ffi.so 自动复制到 flutter_legado/android/app/src/main/jniLibs/ 对应 ABI 目录
- 要求设置 ANDROID_NDK_HOME 环境变量

### Windows 一键构建
- flutter_legado/scripts/build-windows.ps1 实现 Rust DLL + Flutter Windows 应用的完整构建流程
- 自动复制 legado_ffi.dll 到 Flutter 构建输出目录并支持运行

### Flutter 子模块 Makefile
- flutter_legado/Makefile 封装 flutter_rust_bridge_codegen 代码生成、Rust + Flutter 联合测试、APK 构建

## 版本管理与发布策略

### Android 版本号生成
- version = "3." + releaseTime() 基于时间戳生成 versionName
- versionCodeValue 基于 Git 提交计数自增，基础值 37540 从特定 commit 开始计算

### Cronet 版本控制
- gradle.properties 中 CronetVersion=151.0.7922.29 锁定 Chromium 网络库版本
- downloadCronet task 自动生成各 ABI 的 SO 文件 MD5 校验和到 assets/cronet.json

## 构建约束与优化

### 资源优化
- android.enableResourceOptimizations=true 启用资源优化
- android.nonTransitiveRClass=true 启用非传递 R 类减少内存占用
- ProGuard 规则分离为 proguard-rules.pro 和 cronet-proguard-rules.pro

### 构建性能
- org.gradle.jvmargs=-Xmx6g 配置 JVM 堆内存
- org.gradle.vfs.watch=true 启用文件系统监听
- org.gradle.unsafe.configuration-cache=false 禁用配置缓存以保证兼容性

### 多架构支持
- Android NDK 支持 armeabi-v7a、arm64-v8a、x86、x86_64、riscv64 五种架构
- Rust 通过 cargo build --target 交叉编译为不同平台的 .so/.dll 文件

## CI/CD 集成
- GitHub Actions 工作流位于 .github/workflows/ 目录
- Dependabot 自动依赖更新配置在 .github/dependabot.yml
- Release 流程通过 .github/release.yml 管理版本发布
