该模块为纯配置型目录，不包含可执行代码，按 GitHub 官方约定组织：
- `workflows/`：存放 GitHub Actions 工作流（CI/CD），由 `.github/workflows/*.yml` 触发。
- `scripts/`：供 Action 调用的辅助脚本。
- `codex/`：面向 Codex 的提示或说明文件。
- `ISSUE_TEMPLATE/`：Issue 表单模板与全局配置（`config.yml` 禁用空 Issue 并引导至 quick-chinese-transfer 与 Wiki）。
- `dependabot.yml`：统一维护 Gradle、GitHub Actions、npm 三类依赖的自动更新策略，按周周一推送 PR，限制每个生态最多 5 个并发 PR，并将 Kotlin/KSP 相关依赖归入 `kotlin_KSP` 组。
- `release.yml`：定义 Release Notes 的分类规则，通过标签映射到 New Features、Bug Fixes、Performance、Documentation 等分类，支持 `skip-changelog` 排除。
依赖方向单向指向 GitHub 平台能力，不反向依赖项目源码。
