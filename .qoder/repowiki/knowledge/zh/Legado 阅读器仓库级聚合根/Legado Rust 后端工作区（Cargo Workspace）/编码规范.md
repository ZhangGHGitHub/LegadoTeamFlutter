- 所有跨 FFI 的复杂类型统一序列化为 JSON 字符串传递，避免 flutter_rust_bridge opaque 类型问题。
- 错误处理统一使用 thiserror 定义的 LegadoError/LegadoResult，各 crate 通过 thiserror 派生具体错误类型。
- 模块通过 lib.rs 显式 pub mod 声明再在顶层 pub use 重导出，保持公共 API 集中可见。
- 数据模型普遍使用 serde derive（Serialize/Deserialize）并配合 #[serde(skip)] 跳过非序列化字段。
- 异步数据库操作通过 tokio::sync::Mutex 包装非 Sync 的 rusqlite Connection，每次操作获取锁后执行。
- 可选功能通过 Cargo feature flag（如 `quickjs`）条件编译，使用 #[cfg(feature = "...")] 控制代码分支。
