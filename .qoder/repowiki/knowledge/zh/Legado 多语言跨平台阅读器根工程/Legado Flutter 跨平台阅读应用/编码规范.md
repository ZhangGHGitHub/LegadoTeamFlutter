- 所有 Rust FFI 调用集中在 `RustApi` 类中，通过 `bridge.<method>()` 调用生成的桥接函数，返回值统一经 `jsonDecode` + `fromJson` 转换为 Dart 模型对象
- Provider 类统一继承 `ChangeNotifier`，并在构造函数中接收 `RustApi` 实例，通过 `..loadSettings()` 或类似方法在创建时初始化数据
- 路由定义集中在 `AppRoutes` 类中，以 `static const` 声明路径常量，并通过 `routes` getter 返回 `Map<String, WidgetBuilder>`，参数通过 `ModalRoute.of(context)?.settings.arguments` 获取
- Dart 模型类使用 `freezed_annotation` + `json_annotation` 注解配合 `build_runner` 生成不可变数据类和 JSON 序列化代码
- 错误处理通过自定义 `RustApiException` 携带 `operation` 字段区分操作类型，便于上层统一捕获和展示
