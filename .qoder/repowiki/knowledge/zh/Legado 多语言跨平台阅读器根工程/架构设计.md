根目录作为多语言多模块聚合层，按职责划分三个并行演进的业务域：
- `app/` + `modules/`：遗留 Android Kotlin 工程（Gradle 多模块），仍被 `settings.gradle` 包含但已标记为 [旧]；
- `flutter_legado/`：Flutter UI 层，通过 `flutter_rust_bridge` 调用 Rust FFI；
- `rust/`：Cargo workspace 定义的 8 个 crate（core/parser/net/js/book/db/ffi/server），为 Flutter/Dart 提供统一能力。
三者通过 `README.md` 中的项目结构文档与 CI 工作流串联：Rust 负责解析、网络、JS 沙箱与 SQLite 存储，FFI crate 暴露给 Flutter，Android 端逐步替换为 Flutter 前端。根级 `build.gradle`、`settings.gradle` 仅管理 Android 子模块依赖版本与仓库源，Rust 与 Flutter 各自使用 Cargo/Flutter SDK 独立构建，GitHub Actions 在 `rust-ci.yml` 与 `flutter-ci.yml` 中并行验证。
