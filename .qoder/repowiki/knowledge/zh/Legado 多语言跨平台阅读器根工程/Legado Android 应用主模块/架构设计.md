模块采用标准 Android 应用结构，以 `App.kt` 为 Application 入口，在 `onCreate` 中统一初始化崩溃处理、通知渠道、LiveEventBus、Cronet、Rhino 脚本引擎、自动任务调度器、WebDav 同步等全局能力。
- 分层组织：`base/` 提供 BaseActivity/BaseFragment/BaseService/BaseViewModel 等基类；`ui/` 按功能域划分（book、rss、config、autoTask、file 等）；`service/` 承载下载、朗读、视频播放、Web/MCP 服务等前台服务；`model/` 封装业务逻辑（ReadBook、AudioPlay、AutoTask、webBook/localBook/rss 等）；`data/` 基于 Room + DAO + Entities 管理持久化，`schemas/` 保存 95 个版本迁移 JSON；`help/` 存放跨领域工具（http、glide、storage、coroutine、source、config 等）；`utils/` 为通用扩展函数与工具类。
- 依赖方向：UI → model/help/utils → data；service/model 通过协程与 LiveData/Flow 与 UI 通信；外部依赖通过 `cronetlib/` 下的 JAR/AAR 本地引入，并通过 `:modules:book` 和 `:modules:rhino` 两个子模块复用核心能力。
- 构建配置：AGP + Kotlin 17，KSP 替代 kapt 生成 Room 代码，Room schema 输出到 `schemas/`；debug/release 双 BuildType 配合签名与 ProGuard/R8 压缩；资源仅保留 en/es/ja/pt/vi/zh 多语言。
