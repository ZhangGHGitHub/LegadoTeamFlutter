- 所有 GitHub 配置以 YAML 文件形式声明，遵循 GitHub 官方目录约定（workflows、ISSUE_TEMPLATE、dependabot.yml、release.yml）。
- Dependabot 对每个 package-ecosystem 统一设置 `schedule.interval: weekly`、`day: monday` 和 `open-pull-requests-limit: 5`。
- Issue 模板通过 `config.yml` 全局禁用空 Issue，并以 `contact_links` 将用户引导至外部资源（quick-chinese-transfer、Wiki）。
- Release Notes 通过标签（enhancement、feature、bug、fix、performance、documentation 等）映射到分类标题，未匹配的用通配符 `*` 归入 Other Changes。
