# 普通书源搜索出源修复（2.0.38）

编写：Reasonix ｜ 2026-08-12

## 探针基线（修复前）

快速书源 type=0 = 219，关键词「斗破苍穹」：

| 指标 | 2.0.37 前 |
|---|---|
| 有结果源 | 38 |
| 精确书名源 | 19 |
| 总命中 | 686 |

失败分布（逐源）：empty=122（其中 relative_url 特征 62、bookList class. 47）、timeout=15、http:404=14。

## 根因

1. **`charset=gbk` 未用于请求编码**（对齐缺口 `AnalyzeUrl.encodeParams`）
2. **`bookSourceUrl` 的 `#` 唯一后缀污染相对 URL 拼接**（约 48/219）
3. **GBK 响应按 UTF-8 解码** → 书名乱码 → 精确匹配失败

## 修复后

| 指标 | 2.0.38 |
|---|---|
| 有结果源 | **64** |
| 精确书名源 | **45** |
| 总命中 | **1595** |

相对基线：精确源约 **2.4×**，有结果源约 **1.7×**。

## 仍差在哪

- 原版全库顶条聚合 ~336/968；本批仅快速组引擎口径，且大量站点 404/超时/失效。
- 残留：复杂 `source`/`cookie` JS、`webView`、仅 page=1、部分 `class.!0` 索引语义、Rhino 专有绑定。
